# Security policy

Modified firmware can brick hardware. Use **3.3 V** only on XM25QH128C.
Keep a verified `chipdump.bin` before any write.

## Reporting

Open a GitHub issue with: board marking, programmer/software, SHA256 of the
file flashed, and the failure mode. See the [README](README.md) flash section.

This project is **as-is** — no warranty and no guaranteed response time.
